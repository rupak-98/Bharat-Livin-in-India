# Bharat-Livin-in-India
An India-centric mobile life-simulation game where players experience education, careers, finances, relationships, migration and major life events through meaningful choices and evolving consequences. A dynamic life engine that connects player state + regional context + validated socio-economic data to shape branching life-event probabilities.
